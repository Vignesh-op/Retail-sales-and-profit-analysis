📊 Retail Sales & Profit Analysis
📌 Overview

This project focuses on analyzing retail sales data to uncover valuable business insights and support data-driven decision-making. The goal is to help a showroom owner understand sales performance, identify profitable areas, and optimize business strategies using data analysis and visualization techniques.

The project involves data cleaning, exploratory analysis, and dashboard creation to present insights in a clear and actionable format.

🎯 Objectives
Analyze sales and revenue trends
Identify top-performing regions and products
Understand customer segments contributing to profit
Track monthly sales patterns
Build an interactive dashboard for visualization
🛠️ Tech Stack
Python → Data Cleaning & Preprocessing
Microsoft Excel → Business Insights & Data Analysis
Power BI → Interactive Dashboard & Data Visualization
📂 Project Workflow
1. Data Cleaning (Python)
Handled missing values
Removed duplicates
Standardized data formats
Prepared dataset for analysis
2. Data Analysis (Excel)
Created pivot tables
Performed aggregation and filtering
Extracted business insights
3. Data Visualization (Power BI)
Built interactive dashboard
Created charts for:
Sales by Region
Sales by Product Category
Profit by Customer Segment
Monthly Sales Trends
Top Products by Revenue
